O que é o PontoPrime?

O PontoPrime é uma solução completa e moderna para gestão de ponto eletrônico, desenvolvida 100% no Brasil pela AutoManiaAI. Combina tecnologia de ponta com simplicidade de uso, oferecendo autenticação biométrica nativa, geolocalização em tempo real e painel web intuitivo para gestores.

📦 Componentes do Sistema

📱 App Android

Aplicativo nativo desenvolvido em Kotlin com Jetpack Compose. Interface moderna, rápida e intuitiva. Funciona offline e sincroniza automaticamente quando reconecta.

🔐 Biometria Nativa

Utiliza o sensor de impressão digital do próprio celular (BiometricPrompt API). Sem custos com hardware adicional. Segurança validada pelo sistema operacional.

📍 Geolocalização GPS

Captura automaticamente a localização exata do registro de ponto. Identifica endereço, latitude e longitude para auditoria completa.

🌐 Painel Web

Dashboard em tempo real para gestores. Visualize todos os registros, gere relatórios, gerencie funcionários e monitore a jornada de trabalho.

🗄️ Banco de Dados Real

PostgreSQL profissional com backup automático. Dados sempre seguros e acessíveis. Histórico completo preservado indefinidamente.

☁️ Cloud AWS

Hospedado na Amazon Web Services (AWS), garantindo disponibilidade 24/7, escalabilidade e conformidade com LGPD.

📊 Relatórios Completos

Exportação em PDF e Excel. Filtros por funcionário, período, departamento. Dados prontos para integração com folha de pagamento.

🔄 Modo Offline

Registros salvos localmente se sem internet. Sincronização automática quando reconecta. Zero perda de dados.

Preciso comprar celulares novos para os funcionários?

Não! O PontoPrime funciona no celular próprio do colaborador (Android 7.0+). Qualquer smartphone compatível serve. Economia de milhares de reais em hardware.

E se o funcionário não tiver biometria no celular?

O sistema aceita também PIN (senha numérica de 4-6 dígitos) ou reconhecimento facial. É flexível e compatível com 99% dos smartphones Android.

Sim! O PontoPrime está 100% conforme a Portaria MTP 671/2021, que regulamenta o REP-P (Registro Eletrônico de Ponto por Ponto). Auditoria pronta para fiscalização.

Sim! Oferecemos API completa (RESTful) com documentação. Integração com qualquer ERP, folha ou sistema de RH. Também exportamos relatórios em Excel/PDF prontos para importação.
