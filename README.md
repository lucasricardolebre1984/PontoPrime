# PontoPrime - Sistema de Ponto Eletrônico com Biometria Nativa

**PontoPrime** é um sistema de registro de ponto para funcionários remotos, composto por um Aplicativo Android nativo e um Painel de Controle Web. A autenticação é feita via biometria nativa do Android (impressão digital, facial, PIN), garantindo segurança a custo zero.

## Visão Geral

- **App Android:** Kotlin + Jetpack Compose, Retrofit, Room.
- **Backend:** Python com FastAPI (ou Node.js com Express).
- **Painel Web:** React (ou Vue.js).

## Fases do Projeto

1.  **MVP (48h):** Prova de conceito com fluxo simulado.
2.  **Produção:** Implementação completa, segura e escalável.

## Como Iniciar

1.  Clone o repositório.
2.  Configure as variáveis de ambiente em `.env`.
3.  Siga as instruções em `docs/` para rodar o backend e o app.
